Fast health check

sudo nginx -t
sudo systemctl status nginx
sudo journalctl -u nginx -n 100 --no-pager
ss -tlnp | grep nginx
curl -I http://localhost
Good result: configuration test successful, service active, ports listening, and an HTTP response returned.
